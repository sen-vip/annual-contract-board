# 📅 연간계약보드

공개되었거나 비민감한 공공요금·연간계약 정보를 한눈에 정리하고, **이번 달 지출·방문·점검 진행상태까지 시각화하는 브라우저 기반 운영 보드**입니다.

학교 행정실에서 반복적으로 확인해야 하는 연간계약, 공공요금, 자동이체, 증빙, 만료일과 월별 처리상태를 엑셀보다 빠르게 훑고 체크할 수 있도록 만든 보조 도구입니다.

## 🔗 바로가기

- 웹앱: https://sen-vip.github.io/annual-contract-board/
- GitHub: https://github.com/sen-vip/annual-contract-board

## ✨ v1.5 업데이트

- 상단 `예시로 체험하기`로 가상 계약정보, 월별 지출·점검, 종료 임박 현황을 체험
- 체험 데이터는 메모리에서만 사용하며 기존 계약정보와 완료기록은 보존
- `체험 종료` 또는 새로고침 시 기존 데이터로 복귀; 체험 중 내보내기 파일명에 `예시` 표시
- 한글과 숫자가 깔끔한 Pretendard Variable 글꼴 적용 (폰트 파일 포함)
- 앱 안에서 사용 순서, 월간 확인, 엑셀·백업, 저장·알림을 설명하는 도움말 제공
- GitHub 링크는 도움말의 관련 링크로 이동
- 기존 v1.4 저장키를 유지하여 현재 데이터를 그대로 사용

## ✨ v1.4 주요 기능

- `한눈에 보기 / 계약 목록` 2탭 구조
- 앱 진입 시 `한눈에 보기`를 기본 화면으로 표시
- `전체 계약 / 이번 달 지출 / 방문·점검 / 90일 이내 종료` KPI
- 계약 시작일·종료일을 이용한 1~12월 연간 계약 타임라인
- 현재 월을 타임라인에서 은은하게 강조
- 이번 달 지출·방문·점검 대상만 모은 `이번 달 확인할 일`
- 한눈에 보기에서 바로 완료 체크 가능
- 종료 90일 이내 계약을 D-day 순서로 보여주는 `곧 끝나는 계약`
- 시각화 항목을 누르면 계약 목록의 해당 계약으로 바로 이동
- 계약 목록은 검색·필터·추가·수정·삭제·엑셀 작업 중심으로 분리
- 계약 목록 순서 `구분 → 계약명 → ... → 이번 달 → 메모 → 만료상태` 유지
- 입력 폼은 기본 1열 세로형, 계약시작일·계약종료일만 데스크톱 2열
- 학교명·기관명 입력 없이 학년도만 사용
- Figma 스타일의 얇은 탭 indicator, 경계선, 절제된 상태색 중심 UI
- 기존 계약정보와 월별 완료기록을 v1.4 저장키로 자동 마이그레이션
- 별도 서버 DB 없이 현재 브라우저 localStorage에 저장 (실제 사용 모드)

## 🧭 사용 흐름

1. 앱을 열면 `한눈에 보기`에서 이번 달 진행상태와 연간 계약 흐름을 확인합니다.
2. 연간 타임라인에서 계약기간과 현재 월을 함께 살펴봅니다.
3. `이번 달 확인할 일`에서 지출·방문·점검 완료 여부를 바로 체크합니다.
4. `곧 끝나는 계약`에서 재계약·종료 준비 대상을 확인합니다.
5. 계약을 추가·수정하거나 상세 검색이 필요하면 `계약 목록` 탭으로 이동합니다.
6. 필요한 자료는 엑셀 또는 백업 파일로 저장합니다.

## ✅ 월간 확인 기능

월간 확인 기능은 모든 계약에 강제로 적용하지 않습니다.

계약별로 다음 항목을 선택할 수 있습니다.

- 지출 확인
- 방문·점검 확인

예를 들어 복합기 임대는 지출 확인만, 정수기나 승강기 유지관리는 지출과 방문·점검을 함께 사용할 수 있습니다.

완료 기록은 `연-월` 단위로 따로 저장됩니다. 8월에 완료한 기록이 9월 업무를 자동으로 완료 처리하지 않습니다.

기존 버전 데이터를 v1.4로 가져올 때는 `매월 지급` 또는 `자동이체`로 판단되는 계약만 지출 확인 대상으로 이어받으며, 방문·점검 여부는 임의로 추측하지 않습니다.

## 🔔 알림 기능 안내

연간계약보드는 서버 없이 브라우저에서 실행되는 정적 웹앱입니다.

앱이 완전히 닫혀 있거나 컴퓨터가 꺼진 상태에서 자동 푸시 알림을 보내는 구조는 아닙니다. 앱을 열었을 때 오늘 또는 곧 확인해야 할 항목을 보여주며, 필요하면 `.ics` 일정 파일을 만들어 Google Calendar 또는 Outlook에 등록할 수 있습니다.

## 📂 엑셀과 백업

### 엑셀 불러오기 / 내보내기

계약 현황 자료를 가져오거나 정리된 현황을 다시 엑셀 파일로 저장할 때 사용합니다. v1.4 내보내기에는 월간 확인 사용 여부와 현재 달 완료 상태도 포함됩니다.

### 백업 저장 / 불러오기

현재 브라우저에 저장된 계약정보와 월별 완료 기록을 함께 보관하거나 복원할 때 사용합니다.

## 🔐 데이터 및 개인정보

연간계약보드는 **이미 공개되었거나 비민감한 계약정보를 정리·시각화하는 업무 보조도구**입니다.

- 학교명·기관명을 입력받지 않습니다.
- 입력 자료는 별도의 서버 DB에 저장하지 않습니다.
- 현재 사용 중인 브라우저의 localStorage에 저장됩니다.
- 다른 PC나 브라우저로 자동 동기화되지 않습니다.
- 앱 전용 localStorage 저장 키를 사용하며 이전 버전 데이터는 자동 마이그레이션합니다.

다음 정보는 입력하지 마세요.

- 주민등록번호 등 고유식별정보
- 개인 휴대전화번호·개인 이메일
- 계좌번호
- 비밀번호·인증정보
- 공개 전 예정가격·비공개 견적정보
- 그 밖의 개인정보 또는 내부 민감정보

연락처 필드에는 업체 대표번호 등 업무용 연락처만 사용하고, 관리메모에도 개인정보·계좌정보 등 민감정보를 기록하지 않는 것을 권장합니다.

## 🎯 제작 의도

연간계약보드의 목적은 계약자료를 새로 공개하는 것이 아니라, **이미 공개되거나 비민감한 계약정보를 바탕으로 지금 챙겨야 할 일을 빠르게 판단하도록 시각화하는 것**입니다.

한눈에 보기에서는 연간 계약 타임라인과 이번 달 확인사항, 종료 임박 계약을 시각화하고, 계약 목록에서는 검색·수정·엑셀 등 관리 작업에 집중하도록 역할을 분리했습니다.
