# 📅 연간계약보드

공개되었거나 비민감한 공공요금·연간계약 정보를 한눈에 정리하고, **이번 달 지출·방문·점검 진행상태까지 시각화하는 브라우저 기반 운영 보드**입니다.

학교 행정실에서 반복적으로 확인해야 하는 연간계약, 공공요금, 자동이체, 증빙, 만료일과 월별 처리상태를 엑셀보다 빠르게 훑고 체크할 수 있도록 만든 보조 도구입니다.

## 🔗 바로가기

- 웹앱: https://sen-vip.github.io/annual-contract-board/
- GitHub: https://github.com/sen-vip/annual-contract-board

## ✨ v1.3 주요 기능

- `전체 계약 / 이번 달 지출 / 방문·점검 / 90일 이내 종료` 중심 운영 대시보드
- 이번 달 지출 완료 여부 체크 및 진행률 표시
- 이번 달 방문·점검 완료 여부 체크 및 진행률 표시
- 계약별로 지출 확인·방문 확인 항목을 선택적으로 사용
- 월별 완료 기록 분리 저장: 새 달이 되면 새 달 기준으로 자동 전환
- `지출 확인 필요`, `방문 확인 필요` 빠른 필터
- 계약 목록 순서를 `구분 → 계약명 → ... → 이번 달 → 메모 → 만료상태`로 재정리
- 만료상태를 목록 맨 뒤로 이동
- 입력 폼을 한 항목씩 세로로 읽는 1열 구조로 개편
- 계약시작일·계약종료일만 서로 연결된 정보이므로 데스크톱에서 2열 배치
- 학교명 입력 제거 및 기관명 없이 사용 가능
- Figma 스타일에 가까운 얇은 테두리, 정돈된 간격, 절제된 상태색 중심 UI
- 엑셀 불러오기 / 내보내기
- 백업 저장 / 백업 불러오기
- 만료 임박, 증빙, 자동이체, 메모 등 필터·정렬
- 알림일과 알림내용을 활용한 오늘/5일 이내 확인 항목 표시
- 캘린더 일정 파일(.ics) 생성
- 별도 서버 DB 없이 현재 브라우저에 데이터 저장

## 🧭 사용 흐름

1. 엑셀을 불러오거나 계약을 직접 추가합니다.
2. 계약 수정 화면에서 필요한 경우 `지출 확인`, `방문·점검 확인`을 켭니다.
3. 대시보드에서 이번 달 완료 건수와 확인 필요 건수를 확인합니다.
4. 목록의 `이번 달` 열에서 지출·방문 완료를 바로 체크합니다.
5. `지출 확인 필요`, `방문 확인 필요` 필터로 남은 업무만 모아봅니다.
6. 계약 종료가 가까워지면 `90일 이내 종료`에서 재계약·종료 대상을 확인합니다.
7. 필요한 자료는 엑셀 또는 백업 파일로 저장합니다.

## ✅ 월간 확인 기능

월간 확인 기능은 모든 계약에 강제로 적용하지 않습니다.

계약별로 다음 항목을 선택할 수 있습니다.

- 지출 확인
- 방문·점검 확인

예를 들어 복합기 임대는 지출 확인만, 정수기나 승강기 유지관리는 지출과 방문·점검을 함께 사용할 수 있습니다.

완료 기록은 `연-월` 단위로 따로 저장됩니다. 8월에 완료한 기록이 9월 업무를 자동으로 완료 처리하지 않습니다.

기존 v1.2 데이터를 처음 v1.3으로 가져올 때는 `매월 지급` 또는 `자동이체`로 판단되는 계약만 지출 확인 대상으로 이어받으며, 방문·점검 여부는 임의로 추측하지 않습니다.

## 🔔 알림 기능 안내

연간계약보드는 서버 없이 브라우저에서 실행되는 정적 웹앱입니다.

앱이 완전히 닫혀 있거나 컴퓨터가 꺼진 상태에서 자동 푸시 알림을 보내는 구조는 아닙니다. 앱을 열었을 때 오늘 또는 곧 확인해야 할 항목을 보여주며, 필요하면 `.ics` 일정 파일을 만들어 Google Calendar 또는 Outlook에 등록할 수 있습니다.

## 📂 엑셀과 백업

### 엑셀 불러오기 / 내보내기

계약 현황 자료를 가져오거나 정리된 현황을 다시 엑셀 파일로 저장할 때 사용합니다. v1.3 내보내기에는 월간 확인 사용 여부와 현재 달 완료 상태도 포함됩니다.

### 백업 저장 / 불러오기

현재 브라우저에 저장된 계약정보와 월별 완료 기록을 함께 보관하거나 복원할 때 사용합니다.

## 🔐 데이터 및 개인정보

연간계약보드는 **이미 공개되었거나 비민감한 계약정보를 정리·시각화하는 업무 보조도구**입니다.

- 학교명·기관명을 입력받지 않습니다.
- 입력 자료는 별도의 서버 DB에 저장하지 않습니다.
- 현재 사용 중인 브라우저의 localStorage에 저장됩니다.
- 다른 PC나 브라우저로 자동 동기화되지 않습니다.
- 앱 전용 localStorage 저장 키를 사용하며 이전 버전 데이터는 자동 마이그레이션합니다.

다음 정보는 입력하지 마세요.

- 주민등록번호 등 고유식별정보
- 개인 휴대전화번호·개인 이메일
- 계좌번호
- 비밀번호·인증정보
- 공개 전 예정가격·비공개 견적정보
- 그 밖의 개인정보 또는 내부 민감정보

연락처 필드에는 업체 대표번호 등 업무용 연락처만 사용하고, 관리메모에도 개인정보·계좌정보 등 민감정보를 기록하지 않는 것을 권장합니다.

## 🎯 제작 의도

연간계약보드의 목적은 계약자료를 새로 공개하는 것이 아니라, **이미 공개되거나 비민감한 계약정보를 바탕으로 지금 챙겨야 할 일을 빠르게 판단하도록 시각화하는 것**입니다.

단순 계약 목록을 다시 보여주는 데서 끝나지 않고, 이번 달 지출과 방문·점검의 진행상태, 종료가 가까운 계약을 한 화면에서 확인하는 가벼운 운영 보드를 목표로 합니다.
